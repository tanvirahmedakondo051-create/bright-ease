# বিল্ড ব্যাকগ্রাউন্ডে চালানো (স্ক্রিন অফ / অ্যাপ বদলালেও চলবে)

## সমস্যা (নিশ্চিত)
এখন বিল্ডের পুরো কাজটা (AI-এ কোড লেখা, চেক, সেভ) আপনার ফোনের খোলা সংযোগের ভিতরে চলে। স্ক্রিন অফ করলে বা অন্য অ্যাপে গেলে ব্রাউজার সংযোগটা কেটে দেয়, আর সার্ভারের কাজও সাথে সাথে বন্ধ — ফাইল সেভ হয় না।

## সমাধান: বিল্ড হবে সার্ভারের ব্যাকগ্রাউন্ড জব
বিল্ড আর আপনার সংযোগের উপর নির্ভর করবে না। সার্ভারে একটা জব তৈরি হবে, আর সার্ভার নিজে সেটা শেষ করবে — আপনার ফোন যাই করুক।

1. **বিল্ড শুরু = জব তৈরি** — "অনুমোদন করুন" / Build চাপলে সার্ভারে `generation_jobs`-এ একটা জব (queued) লেখা হবে এবং সাথে সাথে "বিল্ড শুরু হয়েছে" উত্তর আসবে। সংযোগ আর ধরে রাখতে হবে না।

2. **সার্ভার নিজে জব চালাবে** — প্রতি মিনিটে চলা সার্ভার-ঘড়ি (আগের cron-এর মতো) queued জব তুলে পুরো বিল্ডটা সার্ভারে শেষ করবে: AI কল, preserve-check, ফাইল সেভ, কয়েন — সব আগের মতোই। প্রতিটা ধাপ জবের `events`-এ লেখা হবে (কোড লিখছি / চেক করছি / সেভ করছি)।

3. **স্ক্রিনে লাইভ অগ্রগতি** — অ্যাপ খোলা থাকলে প্রতি কয়েক সেকেন্ডে জবের নতুন ধাপ দেখাবে (আগের ৮-সেকেন্ড ping-এর বদলে)। স্ক্রিন অফ / অন্য অ্যাপ / অ্যাপ বন্ধ — কিছুই বিল্ড থামাবে না।

4. **ফিরে এলে ফলাফল** — অ্যাপে ফিরলে বা রিফ্রেশ করলে চলমান জব নিজে থেকে খুঁজে নেবে (`activeJob` আগে থেকেই আছে) এবং অগ্রগতি দেখাবে; শেষ হয়ে গেলে নতুন ফাইল ও "যা বদলেছে" তালিকা দেখাবে।

5. **বন্ধ করা** — "জেনারেশন বন্ধ" চাপলে জব cancelled হবে; কয়েন শুধু সফল সেভে কাটবে (আগের নিয়ম অপরিবর্তিত)।

6. **Plan মোড অপরিবর্তিত** — প্ল্যান তৈরি দ্রুত, সেটা আগের মতোই সরাসরি উত্তরে আসবে।

## প্রযুক্তিগত বিবরণ
- `bot.functions.ts`: build/upgrade পথকে জবে ভাগ করা — `startBotBuildJob` (জব insert, দ্রুত রিটার্ন) + `processBotBuildJob(jobId)` (আসল বিল্ড, events আপডেটসহ)। বিদ্যমান build লজিক (`generate()`, preserve-check, সেভ) অপরিবর্তিত রেখে server ফাংশনে সরানো।
- নতুন cron রুট `src/routes/api/public/cron/process-jobs.ts`: প্রতি মিনিটে queued জব তুলে `processBotBuildJob` চালায়; stuck জব (heartbeat পুরনো) failed চিহ্নিত করে। pg_cron এন্ট্রি যোগ — migration ফাইল `supabase/migrations/`-এও।
- `bot.$botId.tsx`: `streamBuild` বাদ; জব শুরু + `getJob`/`job-status` দিয়ে পোলিং (৩ সে), পেজ খুললে `activeJob` দিয়ে resume, Wake Lock আর দরকার নেই (রাখা যায় ঐচ্ছিক হিসেবে — স্ক্রিন জাগিয়ে রাখার বাংলা নোট বাদ)।
- যাচাই: `bunx tsgo --noEmit`, `bunx vitest run src/test`, বিল্ড লগ।
