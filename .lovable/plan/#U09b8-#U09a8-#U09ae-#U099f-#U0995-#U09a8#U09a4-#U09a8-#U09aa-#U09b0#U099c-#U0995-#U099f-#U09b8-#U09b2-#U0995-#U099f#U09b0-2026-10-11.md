# সিনেমাটিক "নতুন প্রজেক্ট" সিলেক্টর

## লক্ষ্য
"নতুন প্রজেক্ট" বাটনে ক্লিক করলে এখন সরাসরি ওয়েবসাইট তৈরি হয় — এর বদলে একটা সিনেমাটিক, মোশন-গ্রাফিক্স স্টাইলের ফুল-স্ক্রিন সিলেক্টর আসবে:

```text
[নতুন প্রজেক্ট ক্লিক]
        │
        ▼
┌─────────────────────────────┐
│  ধাপ ১: কী বানাবেন?          │
│  ┌──────────┐  ┌──────────┐ │
│  │ 🌐 ওয়েবসাইট │  │ 🤖 টেলিগ্রাম বট │ │
│  └──────────┘  └──────────┘ │
└─────────────────────────────┘
        │ বট বেছে নিলে
        ▼
┌─────────────────────────────┐
│  ধাপ ২: কোন ভাষায়?          │
│  ┌──────────┐  ┌──────────┐ │
│  │ 🟩 Node.js │  │ 🐍 Python │ │
│  └──────────┘  └──────────┘ │
└─────────────────────────────┘
```

## কী কী বদলাবে

1. **নতুন `NewProjectDialog` কম্পোনেন্ট** (`src/components/app/NewProjectDialog.tsx`)
   - ফুল-স্ক্রিন ওভারলে: blur + গাঢ় backdrop, ধীরে fade/scale ইন
   - বড় দুটো কার্ড (ওয়েবসাইট / টেলিগ্রাম বট) — hover এ glow, lift, আইকন অ্যানিমেশন; ক্লিকে কার্ড "সিলেক্ট" হয়ে পরের ধাপে slide হয়
   - ধাপ ২ (বট → Node.js / Python) একই স্টাইলে; "পেছনে" বাটন ও Esc/বাইরে ক্লিকে বন্ধ
   - মোশন: `framer-motion` (ইতিমধ্যে ডিপেন্ডেন্সিতে থাকলে) — staggered entrance, spring transition, কার্ডে subtle gradient shimmer; না থাকলে CSS transition দিয়েই একই লুক
   - মোবাইল-ফ্রেন্ডলি: কার্ডগুলো ছোট স্ক্রিনে vertical stack

2. **ড্যাশবোর্ড একীভূতকরণ** (`src/routes/_authenticated/dashboard.tsx`)
   - "নতুন প্রজেক্ট" বাটন এখন ডায়ালগ খুলবে; ওয়েবসাইট বেছে নিলে আগের `newProject()` ফ্লো, বট বেছে নিলে ভাষা অনুযায়ী `createBot` → `/bot/$botId`
   - খালি-অবস্থার "প্রথম ওয়েবসাইট বানান" বাটনও একই ডায়ালগ খুলবে

3. **BotList পরিষ্কার** (`src/components/app/BotList.tsx`)
   - আলাদা "নতুন বট (Node.js)/(Python)" বাটন দুটো সরিয়ে ফেলা — সব তৈরি এখন এক জায়গা (নতুন সিলেক্টর) থেকে; বট-তালিকা শুধু দেখাবে

## টেকনিক্যাল নোট
- শুধু ফ্রন্টএন্ড পরিবর্তন; `createBot` / `newProject` সার্ভার ফাংশন অপরিবর্তিত
- রঙ/স্টাইল existing design tokens (brand, cyan, glass, shadow-glow) ব্যবহার করবে — নতুন হার্ডকোড রঙ নয়
- কোনো নতুন রুট লাগবে না

## যাচাই
- টাইপচেক + প্রিভিউতে Playwright দিয়ে: বাটন → সিলেক্টর → ওয়েবসাইট/বট (দুই ভাষা) তৈরি হয়ে সঠিক পেজে যায় কি না
