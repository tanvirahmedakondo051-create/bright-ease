# Telegram Bot Builder — প্রশ্ন পপআপ ও প্রফেশনাল কন্ট্রোল প্যানেল

## লক্ষ্য
বটের প্ল্যান তৈরির সময় AI-এর প্রশ্ন আর চ্যাটের লেখার মধ্যে দেখানো হবে না। Lovable-এর মতো একেকটি প্রশ্ন পপআপে আসবে, উত্তর নেওয়ার পর পূর্ণ প্ল্যান তৈরি হবে। টোকেন, Telegram Admin ID এবং লাইভ লগ মূল স্ক্রিন থেকে সরিয়ে উপরের একটি কন্ট্রোল বাটনের ভেতর অর্ধ-স্ক্রিন প্যানেলে রাখা হবে।

## ব্যবহারকারীর নতুন ফ্লো
1. ব্যবহারকারী বটের প্রয়োজন লিখে পাঠাবেন।
2. AI-এর আরও তথ্য দরকার হলে ১–৩টি প্রশ্ন একেকটি করে পপআপে দেখাবে।
3. প্রতিটি প্রশ্নে সাজেস্টেড উত্তর, নিজের উত্তর লেখার জায়গা, Skip, Back এবং Next থাকবে।
4. সব উত্তর দেওয়ার পর AI সেই উত্তরসহ পরিষ্কার প্ল্যান দেখাবে।
5. ব্যবহারকারী প্ল্যান অনুমোদন করলে কোড তৈরি হবে।
6. উপরের `Bot Controls` বাটন চাপলে প্রফেশনাল অর্ধ-স্ক্রিন প্যানেল খুলবে। সেখানে টোকেন, Admin ID, বর্তমান অবস্থা, Test/Live/Stop, Telegram-এ খোলা এবং লাইভ লগ থাকবে।

## UI পরিবর্তন
- প্রশ্নের পপআপে progress indicator, নির্বাচিত উত্তরের পরিষ্কার state এবং মোবাইল-ফ্রেন্ডলি বড় controls থাকবে।
- AI প্রশ্ন থাকলে চ্যাটে কাঁচা প্রশ্ন বা JSON দেখাবে না; শুধু উত্তর শেষ হওয়ার পর প্ল্যান দেখাবে।
- বট পেজের উপরে একটি iconসহ `Controls` বাটন থাকবে এবং status indicator দেখা যাবে।
- মোবাইলে কন্ট্রোল প্যানেল নিচ থেকে প্রায় অর্ধেক/দুই-তৃতীয়াংশ স্ক্রিন জুড়ে খুলবে; ডেস্কটপে ডান পাশ থেকে প্রশস্ত panel হিসেবে খুলবে।
- বর্তমান লম্বা `চালান ও লগ` অংশ মূল পেজ থেকে সরবে। মূল জায়গা চ্যাট ও generated files-এর জন্য ব্যবহার হবে।
- লগ terminal-style, auto-scroll, refresh state এবং error হলে `Auto-fix` action রাখবে।
- টোকেন কখনো ফেরত দেখানো হবে না; শুধু সংযুক্ত bot username ও saved status দেখাবে।

## Admin ID
- প্রতিটি বটের জন্য Telegram Admin ID নিরাপদ server action দিয়ে save/update হবে।
- generated Node.js/Python bot code এটিকে environment value হিসেবে পাবে, যাতে order/support/notification admin-এর কাছে পাঠানো যায়।
- ID numeric Telegram user/chat ID হিসেবে validate হবে; invalid value হলে পরিষ্কার বাংলা error দেখাবে।

## Technical details
- Plan-mode AI response structured করা হবে: `questions` থাকলে UI সেগুলো গ্রহণ করবে; উত্তরসহ follow-up request-এর পর final plan তৈরি হবে। Existing bot message JSON-এ structured question/answer metadata রাখা যাবে, তাই প্রশ্নের জন্য নতুন table প্রয়োজন নেই।
- Existing reusable question UI-কে bot flow-এর জন্য Back/Next এবং answer submissionসহ মানিয়ে নেওয়া হবে।
- `bots` table-এ `admin_id` যোগ হবে এবং safe-to-rerun migration `supabase/migrations/`-এ থাকবে।
- Authenticated server function bot ownership যাচাই করে Admin ID save করবে; token-এর বর্তমান encryption অপরিবর্তিত থাকবে।
- VPS launch payload-এ Admin ID যাবে এবং Node/Python process-এ `BOT_ADMIN_ID` হিসেবে inject হবে; secret token handling অপরিবর্তিত থাকবে।
- Existing test/live/stop/log and auto-fix behavior নতুন control panel থেকে একইভাবে কাজ করবে।

## যাচাই
- একটি নতুন বটে এমন prompt পাঠিয়ে দেখা হবে যাতে AI প্রশ্ন করে; popup থেকে একাধিক উত্তর দিয়ে final plan পাওয়া নিশ্চিত করা হবে।
- plan approve করে files তৈরি, Admin ID save, token save এবং Controls panel খোলা/বন্ধ পরীক্ষা করা হবে।
- mobile viewport-এ panel অর্ধ-স্ক্রিনের মতো usable, text/button overlap-free এবং chat usable কি না দেখা হবে।
- Test/Live/Stop ও logs refresh-এর existing flow regression-check করা হবে।
